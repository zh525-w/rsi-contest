## 2. 模型调用信息

- 驱动 Harness 的大模型为 `Qwen/Qwen3.8-27B`，PyTRiO 平台白名单模型，参数量不超过 27B。
- 镜像内通过 `rnd.model(...)` 或 `rnd.transport()` 走平台 host gateway，镜像不含端点与密钥；PyTRiO API Key 只填平台密钥栏。
- 每轮两次调用：训练前选择策略，返回 `{"strategy": i}`；平台测量后决定保留或回滚，返回 `{"select": "candidate"}` 或 `{"select": "parent"}`。
- 回执号写入 `finish(model_call_ids=...)`；提示词与解析规则见 `solution/submission/README.md`。

## 3. 来源声明

- 数据仅来自平台公开包 `cpu-a-guide-20261110-v1`、`cpu-b-rul-20261110-v1`、`cpu-c-guide-20261110-v1` 的 `public/train.jsonl` 与 `public/validation.jsonl`，未使用隐藏集与隐藏标签，未引入外部数据。
- 原始数据来源为 UCI Gas Sensor Array Drift（#224）、XJTU-SY 轴承全寿命数据、NASA C-MAPSS；标签由平台按其公开规则生成，本项目未改写标签。
- 训练与推理代码为本次工作编写，仅依赖 NumPy；官方 SDK 1.0.2 与 `harness.py` 模板按平台提供原样使用。
- 驱动模型由平台提供，本项目未在本地训练或微调该模型。
- 全部指标为本机在公开验证集上的测量值，正式成绩以平台隐藏集评测为准。
